F/A-18 Interceptor @version@

Modern C++/SDL2 port of the 1988 Amiga flight simulator

A reverse-engineered port of Bob Dinnerman’s F/A-18 Interceptor (Intellisoft / Electronic Arts, 1988) to modern C++ with SDL2: 68000 recompilation, Amiga custom-chip HLE, optional OpenGL 3D view, and the original disk loaded at runtime.

Play in the browser Source on GitHub
You need the original ADF. These builds do not include the 1988 game disk — it is not redistributable. Obtain a legal TOSEC copy such as FA-18 Interceptor (1988)(Electronic Arts).adf and supply it yourself: Upload button on the web build, next to the executable on desktop/Windows, app files dir on Android, or the PortMaster port folder on R36S.

Downloads

  • Windows 64-bit Zip with fa18.exe and SDL2.dll — place the ADF beside the exe.
  • Windows 32-bit Same layout for older Windows.
  • Android APK adb push disk.adf into the app files directory.
  • R36S / PortMaster Install via PortMaster; put the ADF in ports/fa18/.
  • Linux / source Build with Nix (nix run github:Grumbel/fa18-interceptor-port) or CMake + SDL2.

Play in the browser

The WebAssembly build runs entirely in your browser. After opening play/, use Upload ADF… once; the image stays in this browser’s storage for that site origin.

Controls

  • ↑ ↓ ← → / numpad — flight stick
  • Space — fire
  • Throttle, views and weapons — as on the Amiga original
  • Gamepads and joysticks via SDL2

About

The original Amiga executable is loaded from the ADF and either interpreted or statically recompiled to C++. OS calls go through high-level emulation; the blitter, copper, Paula and display match the game’s needs. Optional remasters (--hires, --gl, analog stick, text pacing) leave the original behaviour as the default path.

This is an educational reverse-engineering project. The original game remains under its original copyright; new code is GPL-3.0-or-later.
